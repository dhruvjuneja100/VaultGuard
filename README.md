# VaultGuard 🔐

An AI-powered bank statement forensics system that detects 
fraudulent loan applications using Machine Learning and 
document analysis.

## Problem
Loan fraud costs Indian NBFCs thousands of crores annually. 
Fraudsters submit tampered bank statements to secure loans 
they cannot repay.

## Solution
VaultGuard analyzes bank statements and detects:
- Tampered PDF metadata
- Suspicious transaction patterns
- Statistical anomalies in salary credits
- Round number bias in transactions

## Tech Stack
- **Frontend:** React + Tailwind CSS
- **Backend:** FastAPI (Python)
- **ML:** Scikit-learn
- **Database:** PostgreSQL
- **Deployment:** Vercel + Render
